# WanicnDesign

โปรแกรมออกแบบ (ต้นแบบ) ที่จะทำให้เหมือนโปรแกรม QD / Mainmenu V6 ต้นฉบับบน AutoCAD 2007

## สถานะ
- โครงหน้าต่างเมนูหลักตามภาพหน้าจอ (`main.py`) เท่านั้น
- ยังไม่มีการอ่านไฟล์ต้นฉบับจากไดร I หรือ `C:\QD`
- ยังไม่มีสูตรคำนวณ ค่าแรง หรือการสร้างแบบ

## การรัน
```
python main.py
```
ต้องใช้ Python 3 ที่มี tkinter
