# WanicnDesign

โปรแกรมออกแบบอาคาร ถอดปริมาณ และประมาณราคา เขียนด้วย Python
ลำดับการทำงานอ้างอิงจากคู่มือและวิดีโอของโปรแกรมเดิม (สรุปไว้ใน `docs/workflow.md`)
แต่โค้ดและสูตรคำนวณเขียนใหม่ทั้งหมด ไม่ได้คัดลอกจากโปรแกรมเดิม

## ช่วงที่ 1 (เวอร์ชันนี้): ปริมาณงานและค่าแรง
- ถอดปริมาณ: งานดิน คอนกรีต ไม้แบบ เหล็กเสริม ก่อ ฉาบ ทาสี ประตูหน้าต่าง หลังคา
- การเผื่อตามเกณฑ์กรมบัญชีกลาง พ.ศ. 2569 (เหล็กตามขนาด ขุดดิน ทรายรอง กระเบื้องหลังคา)
- ค่าแรงตามบัญชี **ว480 (26 มิ.ย. 2569)** 78 รายการ ใน `data/labour_2569.json`
- ใบประมาณราคาแบบ ปร.4 ส่งออก Excel พร้อมสูตร (แก้ราคาใน Excel แล้วยอดรวมเปลี่ยนตาม)
- วาดกริดและร่างเสา: บันทึกเป็น DXF หรือวาดลงใน AutoCAD ที่เปิดอยู่ (ผ่าน COM)

## ช่วงที่ 2: โมเดลอาคารและการคำนวณโครงสร้าง
สร้างโมเดลบนกริดก่อน (ไฟล์ตัวอย่าง `examples/building_2storey.json`) แล้วคำนวณไล่ลำดับ
หลังคา (แป จันทัน) → พื้น → คาน → เสา → ฐานราก → เสาเข็ม แล้วทำ BOQ จากผลออกแบบ

```
python -m wanicndesign design examples/building_2storey.json -o ผลออกแบบ
```
ได้ไฟล์ `รายการคำนวณ.xlsx`, `แบบโครงสร้าง.dxf` (แปลนทุกชั้น + โมเดล 3 มิติ), `ราคากลาง-ปร.xlsx`

แผนการพัฒนาช่วงถัดไปอยู่ใน `docs/ROADMAP.md`

## ติดตั้ง
```
pip install -r requirements.txt
```

## ใช้งานผ่านหน้าจอ (ช่วงที่ 3)
```
python main.py
python main.py examples/building_2storey.json
```
- ซ้าย: ขั้นตอน 1–7 (โครงการ, กริด, ชั้น พื้น คาน, ฐานราก/เสาเข็ม, หลังคา, แผ่นดินไหว, ผลคำนวณ)
- แผ่นดินไหว: เปิดใช้ในขั้นที่ 6 ตาม มยผ. 1301/1302-61 (วิธีแรงสถิตเทียบเท่า) ดูสูตรและที่มาใน `docs/STANDARDS.md`
- กลาง: แปลนรายชั้น คลิกเสา คาน หรือพื้นเพื่อลบ คลิกเส้นประเพื่อคืน และมุมมอง 3 มิติ (ลากเพื่อหมุน)
- กด **คำนวณโครงสร้าง** (F5) ชิ้นส่วนเปลี่ยนเป็นสีเขียว (ผ่าน) หรือแดง (ไม่ผ่าน) พร้อม Mark
- ส่งออก รายการคำนวณ Excel, แบบ DXF, ราคากลาง (แบบ ปร.4 ปร.1 (ก) ปร.1) · ย้อนกลับด้วย Ctrl+Z · บันทึกโมเดลเป็น .json

## ใช้งานผ่านคำสั่ง
```
python -m wanicndesign estimate examples/house_8x12.json -o BOQ.xlsx
python -m wanicndesign prices examples/house_8x12.json -o prices.json
python -m wanicndesign estimate examples/house_8x12.json --prices prices.json -o BOQ.xlsx
python -m wanicndesign estimate examples/house_8x12.json --labour-up 5 -o BOQ.xlsx
python -m wanicndesign labour
python -m wanicndesign labour --set 2.3.1a 110
python -m wanicndesign plan examples/house_8x12.json -o plan.dxf
python -m wanicndesign plan examples/house_8x12.json --autocad
```

## อัปเดตค่าแรง
- ปรับรายการเดียว: `labour --set รหัส ราคา` หรือปุ่ม "แก้ค่าแรงรายการ" ในหน้าต่างปริมาณ
  ค่าที่แก้จะบันทึกแยกไว้ใน `data/labour_override.json` ตาราง ว480 ต้นฉบับไม่ถูกแก้
- ปรับทุกรายการเป็นร้อยละ: `--labour-up 5` หรือปุ่ม "ปรับค่าแรงทั้งหมด %"
- เมื่อมีบัญชีค่าแรงฉบับใหม่ ให้แก้ตารางใน `3d/core/wanic_std2569.py`
  แล้วรัน `python design/WanicnDesign/tools/export_labour.py`

## ราคาวัสดุและราคากลาง (หลักเกณฑ์กรมบัญชีกลาง 2569)
ราคาวัสดุเป็นของผู้ใช้ (สำนักงานพาณิชย์จังหวัดหรือร้านค้า) โปรแกรมไม่มีราคาในตัว
- ค่าวัสดุต่อหน่วยงานคิดจาก **สูตรวัสดุมวลรวม กรมบัญชีกลาง 2569** (หน้า 104–170 รวมเผื่อแล้ว) × ราคาวัสดุ
  เช่น ผนังก่ออิฐมอญครึ่งแผ่น = สูตร 6.1 (อิฐ 138 ก้อน ปูน 16.01 กก. …), ไม้แบบ = A(0.133)+B(0.774)+C(0.25)
- ราคาวัสดุรายจังหวัดเก็บเป็น "สมุดราคา" โฟลเดอร์เดียวกับโปรแกรม WANICNSURVEY 3D (ใช้ร่วมกันได้):
  หน้า 9 "ราคากลาง" กดนำเข้าตารางพาณิชย์จังหวัด (.xlsx/.csv) หรือกรอกเองในตาราง หรือคำสั่ง
  `python -m wanicndesign province BUILDING.json ขอนแก่น ตาราง.xlsx`
- Factor F กรอกค่าเดียว หรือกรอกแถวจากตาราง Factor F ฉบับที่ใช้ (โปรแกรมเทียบอัตราส่วนระหว่างช่วง);
  วิธีราชการ Factor F รวม VAT แล้ว, งานเอกชนบวก VAT
- ส่งออก แบบ ปร.4 (สรุปราคากลาง + ตัวอักษร) ปร.1 (ก) (สรุป × Factor F) ปร.1 (รายการ) พร้อมแผ่นราคาวัสดุ
  และวิเคราะห์ค่าวัสดุ (ที่มาทุกบรรทัด) ทุกยอดเป็นสูตร Excel
- ใช้คำสั่ง `prices` สร้างไฟล์รายการวัสดุ แล้วกรอกราคาต่อหน่วย (ราคาที่กรอกตามชื่อรายการ BOQ ยังใช้ได้และมีผลก่อน)

## ข้อจำกัดของเวอร์ชันนี้
- ปริมาณคอนกรีตคานคิดเต็มความลึก (ยังไม่หักส่วนที่ซ้อนกับพื้น)
- เหล็กเสริมคิดตามความยาวชิ้นส่วน ยังไม่รวมระยะทาบและงอ นอกจากขอปลอก
- กฎทับหลังตามภาคผนวกคู่มือเดิม ยังไม่ได้ตรวจกับโปรแกรมเดิม
- ส่วน AutoCAD (COM) ยังไม่ได้ทดสอบบนเครื่องจริง ทดสอบเฉพาะส่วน DXF
- ข้อจำกัดของการคำนวณโครงสร้างดูท้ายไฟล์ `docs/ROADMAP.md`
