# มาตรฐานและที่มาของ WanicnDesign

ทุกค่าและทุกสูตรในโปรแกรมอ้างรหัสในตารางนี้ (ดูโค้ดใน `wanicndesign/standards.py`)
รายงานคำนวณและ BOQ มีแผ่น **มาตรฐานและที่มา** ที่แสดงเฉพาะรายการที่ใช้จริงในโครงการนั้น

## สถานะของแหล่งอ้างอิง

- **document** — จากเอกสารที่ได้รับ
- **recall** — จากมาตรฐานที่เผยแพร่ทั่วไป ต้องตรวจกับฉบับจริงก่อนใช้ขออนุญาต
- **project** — ต้องใช้ข้อมูลจริงของโครงการ
- **textbook** — หลักการคำนวณพื้นฐานตามตำราวิศวกรรมโครงสร้าง

> รายการที่สถานะเป็น recall เขียนจากมาตรฐานตามที่เผยแพร่ทั่วไป ยังไม่ได้เทียบกับเล่มจริงในโครงการนี้
> ก่อนใช้ผลคำนวณยื่นขออนุญาต ต้องตรวจกับฉบับที่มีผลบังคับใช้ และให้วิศวกรผู้มีใบอนุญาตลงนาม
