# ReadWanicn2027

โปรแกรม PDF สำหรับใช้งานภายในองค์กร — พัฒนาโดย นายเวนิช ธัมมะวงษ์ วิศวกรสำรวจ

- รวมไฟล์ PDF · บีบอัด 3 ระดับ (คุณภาพสูง / กลาง / ต่ำ) · บันทึก · บันทึกเป็น · ลบหน้า · หมุนหน้า · ลบไฟล์
- ส่งออกข้อความและตารางในเอกสารเป็น Excel / CSV / Word
- ตั้งสเกล (1:N หรือคลิก 2 จุดบนระยะที่รู้ค่า) · วัดความยาว · คิดพื้นที่ · นับจำนวน · รายงาน Excel/CSV · บันทึกงานวัด (.json)
- ย่อ/ขยาย/พอดีจอ · ซ่อน/แสดงเมนูและแผง · 5 ธีม · หมุนโมเดล 3 มิติ (.stl .obj)
- หน้าต้อนรับพร้อมโลโก้ · เข้าสู่ระบบ · แสดงจำนวนดาวน์โหลดและเวอร์ชันใหม่จากหน้า Releases (แท็ก `readwanicn-v…`)

รันจากซอร์ส:

```
pip install -r requirements.txt
python main.py
```
