# ข้อมูลข้อบัญญัติในชุดโปรแกรม

## `maikhao_2570.csv` — องค์การบริหารส่วนตำบลไม้ขาว อำเภอถลาง จังหวัดภูเก็ต

- ที่มา: ข้อบัญญัติงบประมาณรายจ่ายประจำปีงบประมาณ พ.ศ. 2570 (เอกสารเผยแพร่สาธารณะ 292 หน้า)
  https://www.maikhaow.go.th/ebook_banyad/detail/18/data.html
  ไฟล์ PDF: https://www.maikhaow.go.th/files/com_ebook_banyad/2026-09_28ac2fa9af49811.pdf
- แปลงจาก «รายงานประมาณการรายจ่าย» (หน้า 25–123 ของไฟล์) ด้วย `tools/ordinance_pdf.py`
- 750 รายการ รวมประมาณการปี 2570 = 205,000,000 บาท ตรงกับข้อ 4 ของข้อบัญญัติทุกแผนงาน
- คอลัมน์: แผนงาน, งาน, งบ, หมวด, ประเภท, รายการ, ประมาณการ 2570, หมายเหตุ,
  รายจ่ายจริง 2567, รายจ่ายจริง 2568, ประมาณการ 2569, หน้า (ในไฟล์ PDF), คำชี้แจง
- คำชี้แจงจาก «รายงานรายละเอียดประมาณการรายจ่าย» (หน้า 124–292) ได้ 465 จาก 469 รายการที่มีงบประมาณ
  (แก้รหัสวรรณยุกต์ของฟอนต์รุ่นเก่า U+F700–F71A ให้เป็นอักษรไทยมาตรฐาน)

## `maikhao_2569.csv` — ข้อบัญญัติปี 2569 ของ อบต.ไม้ขาว

- ที่มา: https://www.maikhaow.go.th/ebook_banyad/detail/14/data.html
  ไฟล์ PDF: https://www.maikhaow.go.th/files/com_ebook_banyad/2025-09_268977c4f30f076.pdf (307 หน้า)
- 842 รายการ รวม 198,806,800 บาท ตรงกับยอดรวมข้อ 4 และตรงกับบรรทัด «รวมแผนงาน…» ในรายงานทุกแผนงาน
  ข้อสังเกต: ตารางข้อ 4 ของต้นฉบับปี 2569 แยกรายแผนงานต่างจากรายงานเล็กน้อย
  (บริหารงานทั่วไป −6,820 · ศาสนาฯ −13 · โยธา −6,840 · พาณิชย์ +33 บาท) แต่ยอดรวมเท่ากัน
- คำชี้แจง 494 จาก 498 รายการที่มีงบประมาณ

## หลักการ: แต่ละปีใช้ข้อบัญญัติของปีนั้น
นำเข้าแล้วเฉพาะคอลัมน์ «ประมาณการ» ของปีข้อบัญญัติเป็นงบประมาณของปีนั้น; คอลัมน์ปีอื่นเก็บเป็น
ตัวเลขอ้างอิงเพื่อเปรียบเทียบหลายปีเท่านั้น — ปีที่มีข้อบัญญัติของตัวเองในโปรแกรมจะใช้ของตัวเองเสมอ
- 20 รายการ ต้นฉบับไม่พิมพ์หัว «ประเภท» โปรแกรมเติมจากรายการชื่อเดียวกัน (ระบุในหมายเหตุ)
  และ 1 รายการระบุว่า «(ไม่ระบุประเภทในต้นฉบับ)» — ให้เจ้าหน้าที่ตรวจกับต้นฉบับ
