# พัสดุเวนิช (VENIT SUPPLY)

โปรแกรมบริหารพัสดุภาครัฐ สำหรับ Windows — ตามระเบียบกระทรวงการคลังว่าด้วยการจัดซื้อจัดจ้าง
และการบริหารพัสดุภาครัฐ พ.ศ. 2560 หมวด 9 (การบริหารพัสดุ)

ผู้พัฒนา: นายเวนิช ธัมมะวงษ์ วิศวกรสำรวจ · โปรแกรมใช้ได้ฟรี ไม่มีค่าลิขสิทธิ์ · GPL-3.0

## งานที่ทำได้ (รุ่น 2026.11.13.2)

| หน้า | งาน |
|---|---|
| งบประมาณ | ข้อบัญญัติงบประมาณรายจ่าย แผนงาน › งาน › งบ › หมวด › ประเภท › รายการ · โอนเพิ่ม/ลด · ข้อบัญญัติเพิ่มเติม · คงเหลือ · นำเข้าตาราง · หลายปี |
| จัดซื้อจัดจ้าง | ซื้อ จ้าง เช่า แลกเปลี่ยน — ขออนุมัติ › อนุมัติ › ใบสั่ง/สัญญา › ตรวจรับ › เบิกจ่าย; แสดงมีเงินเท่าไร ครั้งนี้ เหลือเท่าไร |
| สถิติ | รายวัน รายเดือน รายปีหลายปี: วงเงินที่ขอ ก่อหนี้ผูกพัน เบิกจ่าย และแยกตามวิธี ประเภท หมวด ผู้ขาย |


| หน้า | งาน |
|---|---|
| หน้าหลัก | สรุปจำนวน/มูลค่าครุภัณฑ์ มูลค่าสุทธิ ค่าเสื่อมปีนี้ วัสดุคงเหลือ ยืมอยู่/เกินกำหนด ผลตรวจประจำปี · แผงผู้พัฒนา |
| ครุภัณฑ์ | ทะเบียนครุภัณฑ์ ออกเลขรหัสอัตโนมัติ `{org}-{type}-{seq:04d}/{fy}` · ทะเบียนคุมทรัพย์สินพร้อมตารางค่าเสื่อม · ยืม · จำหน่าย (ข้อ 215) |
| วัสดุ | รับเข้า/เบิกจ่าย บัญชีวัสดุ คิดราคาเข้าก่อนออกก่อน (FIFO) · จุดสั่งซื้อ · ใบเบิกพัสดุ |

| ตรวจสอบประจำปี | บันทึกผลตรวจนับ (ข้อ 213) ปรับสถานะครุภัณฑ์อัตโนมัติ |
| รายงาน | บัญชีครุภัณฑ์ · ค่าเสื่อมราคาประจำปี · วัสดุคงเหลือ · ทะเบียนยืม · ผลการตรวจสอบประจำปี · ทะเบียนจำหน่าย — พิมพ์ PDF / ส่งออกตารางคำนวณ |
| ตั้งค่า | ข้อมูลหน่วยงาน ผู้ลงนาม เกณฑ์ราคา 10,000 บาท ราคาซาก 1 บาท รูปแบบเลขรหัส อายุการใช้งานตามประเภท |

ค่าเสื่อมราคา: วิธีเส้นตรง (ราคาทุน − ราคาซาก) ÷ อายุการใช้งาน; ปีแรก/ปีจำหน่ายคิดตามจำนวนวัน ÷ 365,
ปีที่ใช้เต็มปีคิดเท่ากับค่าเสื่อมต่อปี; ปีงบประมาณ 1 ต.ค. – 30 ก.ย.

ข้อมูลทั้งหมดอยู่ในไฟล์เดียว `.vsdb` (SQLite) ค่าเริ่มต้น `เอกสาร\VenitSupply\พัสดุ.vsdb`.
เมนูภาษาไทย/English (แบบฟอร์มราชการพิมพ์เป็นภาษาไทยเสมอ).
