# พัสดุเวนิช (VENIT SUPPLY) 2026.11.13.4 (ทดสอบ)

**ปรับหน้าจอให้เข้ากับคอมพิวเตอร์แต่ละรุ่น** (จากผลทดสอบของเจ้าของ)
- ขนาดตัวอักษรเลือกตามฟอนต์ที่มีในเครื่องและขนาดจอ (รวมการขยายจอ 125 % / 150 % ของ Windows)
- ปุ่ม «บันทึก» «ยกเลิก» อยู่ล่างหน้าต่างเสมอ ฟอร์มยาวแบ่งเป็น 2 คอลัมน์และเลื่อนดูได้
- หน้าต่างไม่ใหญ่เกินจอ จอเล็กเปิดเต็มจออัตโนมัติ แต่ละหน้าเลื่อนดูได้เมื่อพื้นที่ไม่พอ
- ช่องปีงบประมาณกว้างขึ้น ตัวหนา อ่านง่าย; ตัวอักษรทั้งโปรแกรมใหญ่ขึ้น

## รุ่นแรก 2026.11.13.3

โปรแกรมบริหารพัสดุภาครัฐ สำหรับ Windows — ใช้ได้ฟรี ไม่มีค่าลิขสิทธิ์

- **งบประมาณตามข้อบัญญัติ** แผนงาน › งาน › งบ › หมวด › ประเภท › รายการ แต่ละปีใช้ข้อบัญญัติของปีนั้น
  โอนเพิ่ม/ลด ข้อบัญญัติเพิ่มเติม คงเหลือ คำชี้แจงของแต่ละรายการ
- **นำเข้าข้อบัญญัติ** อ่านไฟล์ PDF ข้อบัญญัติ (ระบบ e-LAAS) ตรวจยอดกับเล่ม แสดงรายการและคำชี้แจงก่อนบันทึก
  มีข้อบัญญัติ อบต.ไม้ขาว ปี 2569 และ 2570 ในชุดโปรแกรม
- **จัดซื้อ จ้าง เช่า แลกเปลี่ยน** ขออนุมัติ › อนุมัติ › ใบสั่ง/สัญญา › ตรวจรับ › เบิกจ่าย
  แสดง «มีเงินเท่าไร ครั้งนี้ เหลือเท่าไร» ทุกขั้น ภาษีหัก ณ ที่จ่าย ค่าปรับ
- **สถิติ** รายวัน รายเดือน รายปีหลายปี
- **ครุภัณฑ์** เลขรหัส ค่าเสื่อมราคา ทะเบียนคุม · **วัสดุ** บัญชีวัสดุ FIFO · **ยืม-คืน** · **ตรวจสอบประจำปี**
- **รายงาน** PDF และตารางคำนวณ เป็นแบบฟอร์มราชการภาษาไทย

เครื่องมือช่วยงาน — ตรวจสอบกับระเบียบและข้อบัญญัติของหน่วยงานก่อนใช้งานจริง
