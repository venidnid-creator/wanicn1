# WANICNSURVEY

ชุดโปรแกรมงานสำรวจ เขียนแบบ 2 มิติ และขึ้นโมเดล 3 มิติ ภาษาไทย ใช้งานได้ฟรี
พัฒนาต่อยอดโดย **นายเวนิช ธัมมะวงษ์ วิศวกรสำรวจ (2569)**

| ส่วน | โฟลเดอร์ | มาจาก |
|---|---|---|
| หน้าเริ่มต้น WANICNSURVEY | `launcher/` | เขียนใหม่ |
| WANICNSURVEY CAD (2 มิติ + งานสำรวจ + ภูมิประเทศ) | `cad/` | [IngeCAD](https://github.com/ingelibre/ingecad) 0.6.7 |
| WANICNSURVEY 3D | `3d/` | [IngeTrazo](https://github.com/ingelibre/ingetrazo) 0.5.8 |
| โลโก้เข็มทิศ ไอคอน | `branding/` | ออกแบบใหม่ |
| ตัวติดตั้งภาษาไทย | `installer/` | Inno Setup |

## สิ่งที่เปลี่ยนจากต้นฉบับ
- ภาษาไทยครบทั้งสองโปรแกรม (5,486 ข้อความ) และเปิดเป็นภาษาไทยตั้งแต่ครั้งแรก
- ชื่อ ไอคอน และหน้าต่าง "เกี่ยวกับ" เป็น WANICNSURVEY โดยยังคงเครดิตผู้พัฒนาเดิมไว้ครบ
- เมนู **2D ⇄ 3D** สลับระหว่างสองโปรแกรม และกลับไปหน้าเริ่มต้นได้
- หน้าเริ่มต้นแบบการ์ดสองใบ พร้อมรายการไฟล์ล่าสุดและลากไฟล์มาวางได้
- ตัวติดตั้งตัวเดียวเป็นภาษาไทย: ติดตั้งทั้ง 3 ส่วน สร้างไอคอน และผูกไฟล์ .igz / .dwg / .dxf
- รูปแบบไฟล์ (.dwg .dxf .igz) ไม่เปลี่ยน ใช้แลกเปลี่ยนกับ IngeCAD/IngeTrazo และ AutoCAD ได้ตามเดิม

ไฟล์ที่แก้ไขในซอร์สต้นฉบับทั้งหมดทำโดย `tools/apply_branding.py`
(ชื่อที่แสดงอยู่ใน `cad/core/branding.py` และ `3d/core/branding.py`)

## วิธีสร้างตัวติดตั้ง (.exe)

**ทางที่ 1 — GitHub Actions (แนะนำ ไม่ต้องติดตั้งอะไรในเครื่อง)**
1. อัปโหลดโฟลเดอร์นี้ขึ้น GitHub repository ของคุณ
2. แท็บ **Actions** ▸ **build-windows** ▸ **Run workflow**
3. รอประมาณ 30–40 นาที แล้วดาวน์โหลด `wanicnsurvey-setup-….exe` จากหัวข้อ Artifacts
   (หรือ push tag เช่น `v2026.10.28` เพื่อแนบไฟล์ติดตั้งไว้ในหน้า Releases)

**ทางที่ 2 — สร้างบนเครื่อง Windows ของคุณเอง**
1. ติดตั้ง Python 3.12 (64-bit, ติ๊ก Add to PATH), Git และ Inno Setup 6.5 ขึ้นไป
2. ดับเบิลคลิก `build-windows.bat`
3. ไฟล์ติดตั้งจะอยู่ในโฟลเดอร์ `dist\`
